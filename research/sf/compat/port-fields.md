## 5. How to use this table

The final local check (V08 §3.16 (9) (c)) walks §1 path by path against SettlementForge's checkout at the owner's commit: present or absent, shape and type as the `type` column states, values sampled against the `values` column's row-set words; each fallback against a dossier that lacks the field; the key lists of the outcome paragraph; §2's fields for presence and shape; §4's findings settled. Its result rows: `match`, `mismatch` with a fix (an adapter version with remaps, a field-table row, a row-set word, a fallback), `new` for a path no row names.

# The host rulings that bind the map — a mirror

> PENDING FABLE REVIEW — written by Opus 5.5 under the J375 addendum; to be retrovalidated by a Fable seat.

**What this is.** The owner rules in two chairs: the map program's (this repository's `docs/PROGRESS.md`) and the host's
(SettlementForge's fold `docs/DESIGN_FP_COHERENCE_FOLD.md` and its decision queue `docs/OWNER_DECISION_QUEUE.md`, on the
host's master). Until 2026-10-24 the host's rulings reached this program only when a host read happened to cite them, and
twice that failed: the map re-asked a question the owner had closed in the host (patrols and capture, closed 2026-10-18)
and ruled a question that was the owner's in the host (the deity at birth). This file mirrors every host ruling that
binds the map, with its source, what it binds here, and the map-side record that carries it (`docs/PROGRESS.md` J400).

**The rule of use.** Before any host prompt, any new H row of V13 §8.5 or any map ruling that touches a host fact: read
this file. A host answer or a host ruling that reaches this program is appended here the day it arrives, with its date
and source. A map ruling that would contradict a row here is not made; it is asked of the owner in the host's chair.
Cite the host's fold by section and row, never by line (the host: "every number here is stable"); the host's records are
on its master; no prompt claims the owner's authority — the owner dispatches each host unit in chat.

**Sources.** H = the host's answer of 2026-10-24 (`research/sf/host-reply-2026-10-24.md`; the host's fold §3.1.38, §7
OD-FC-134 – OD-FC-136, the decision queue §934.99, the host PR #66 merged `8b82e3d04`). Earlier rows name their source.
The host's design names (`polityOf`, `whereaboutsOf`, `presentAt`, `lastHeard`, `pastCauseOf`, `pastRef`,

Item 101 R2 (docs/AMENDMENTS-2026-09-27e.md l. 102–105, an OWNER RULE): "The tool bends a declaration to the nearest lawful one and says so in one gentle line; it refuses only what item 20 forbids (dossier facts) and what a lock protects, always with the closest alternatives."

Hazard seen 2026-09-29 (critique-V2 §11, V2C-47, blocker): volume 2's item-110 fold refused five tier/deck edits ("internal over a solid tier 0", "removeWing on a stair", towers/ranges on a stepped building, "family stepped on a deck", tiers op on a non-stepped building) and the revision two more (last wing, row-quad reshape); critique-V9's V9C-59 (4) then proposed WIDENING volume 9's refusal list to admit them — which edits the design around the owner rule. The fix is bends (e.g. a sealed `none` stair form, ground wings beside a stack, `single` on a deck, T6 remove for the last wing, the plot line for a row quad).

**Why:** owner rules outrank volumes; a "refused, offering X" is still a refusal under R2.
**How to apply:** when reviewing or writing any edit op, check every "refused" against R2's two classes; convert the rest to named bends. See [[wired-architecture-directive]], [[owner-profile]].

Applied 2026-09-29 by volumes/revise-V2 (second round): all seven turned into named bends (V2 §4.2, §4.3, §4.6; J-V2.79), and a grep for "refus" found four MORE the critique had not listed (a wing below 4 m² → grown; an op beyond the plot → clipped with `join` offered; a gate hall with no gate range → a gate passage; an unreachable `family` → the nearest reachable one). How to apply: when fixing an R2 finding, grep the whole volume for "refus"/"F-EDIT" and sweep the class, not only the cited instances; the base's own requested-basement ladder end "(4) a refusal naming the gate" was left to the base (cited, not re-ruled).

Applied 2026-09-29 by volumes/_integrate's continuation (J-VI.30, file f item 582): three refusals that volume 9's message table mirrored from a PRE-item-101 base sentence (§7.1: a user's placement no plot fits, one over its disruption budget, and a join/split removing an occupied building "returns F-EDIT") became bends (`bend.place.noSite`, `bend.place.overBudget`, `bend.vacate`; accepting the dry run is item 31's demolition confirmation); an assignment or a rejectSite re-placement that no plot fits stays F-EDIT (a dossier fact's conflict). How to apply: the base itself still carries pre-item-101 refusal sentences — when a volume renders a base refusal, check it against R2 before copying it.

above), so §4.7's re-provision of a dossier household's housing inside its district — and any dossier element's placement —
places only where the district holds an unlocked site. At generation it always does: locks are edits, none precedes the

author naming the locks (unlock, choose another site or keep the lock, as any lock meeting a dossier element does above);
the request of a dossier event returns the same F-EDIT to the host, which unlocks first (J-DET-11); and an epoch's request
widens to the town as J-A20.43's does — the nearest district by the same least-disruption order, reported — so a dossier
household is never dropped and a lock is never written. §4.7's and §5.2 F-SITING's "always places" read with this paragraph.

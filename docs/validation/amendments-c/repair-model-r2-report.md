**Deviations from the verifiers' texts (each recorded here).**

2. V-MC1-01 is widened by two clauses that close lifecycle paths its text left open. First, when a dossier set displaces
   a user's `edit`, that edit is reported and orphaned (J-A20.73). Second, a use whose re-resolved mode is `none` is
   placed as an open use. `Use.concealment`'s "resolved once" is also qualified ("re-resolved only when a dossier event
   withdraws the dossier's mode"), so the two adjacent comments agree; it asserts nothing about the fallback chain of

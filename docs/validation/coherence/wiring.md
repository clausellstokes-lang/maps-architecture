## 1 Method

1. **Pieces** are read from the text, not from memory: records, fields, interfaces and methods from every code block (634 declarations); the volumes' §1b wiring tables by their column headers (piece, producer, consumer, base hook; edit, tool, lifecycle, undo; entity, rendered, labelled, exported, persisted; dossier fact, field, derivation row); the base's structured tables (§7.1's tools and events, §7.4's lifecycle rows, §7.7's derivation table, V11 §3.1's table registry, §14's package chain); tests and derivation rows by id; the inventories' items with their `reads` / `used_by` / `wiring` fields as fact nodes (their unresolvable free-text references, 7564, are counted and not guessed).
2. **Detectors** raise candidates: a field named nowhere outside its declaration (189); a §1b row naming another volume whose text never names the piece (99 keyed, 78 described only in words); a test or derivation row referenced but never defined; a table with no reader; an interface with no implementer or caller; a failure class with no test; a package outside §14; an edit row without tool, lifecycle row or undo; an entity row without a column. **Every candidate was reviewed** in the text (the other end searched by its concept, not only its identifier); the verdicts are in `wiring-verdicts.json` and a re-run over a rewritten text reports any new candidate as UNREVIEWED.
3. **The dossier** is traced from SettlementForge's own fields (research/sf/dossier-model.md; the 77 rows of research/sf/mapping.md with the 18 corrections of research/sf/mapping-verify.md, which bind) through the neutral digest (§14, V08 §2.5), the derivation rows (§7.7 DR1-DR25, the volumes' DR26-DR35 of file f item 383) and the change path (the envelope, the fold, the mutation, the re-derivation) to the facts they reach.
4. **Inventory findings** about wiring (the inventories' wiring_gaps, wiring_observations and wiring_findings) are adopted after checking their text is unchanged; the missing parts of g items 111-113 and the J122 answers stay with the canon's F-MISSING routing (§8).

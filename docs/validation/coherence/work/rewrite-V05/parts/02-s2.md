
## 2 Data model

### 2.1 The island record

`SkyIsland`, `UndersideProfile` and `ShadeBasis` are declared in `@plat/model` as this section gives them (§2.7 names
the fields the base reads).

```ts
// every length integer cm, every value on the field's [0, 1] scale
interface SkyIsland {
  id: Id                          /* 'sky<part>/island:<token>' (§6.3) */;
  slot: 1 | 2 | 3                 /* the count law's ordered slot it fills (V05 §3.2); a fallen island frees it; a removed one holds it closed until `removed.releasedBy` is set (V05 §3.2 (6)) */;
  key: PlatKey                    /* { layer: 'sky', part }: part taken from Document.nextSkyPart at creation, never reused */;
  anchor: PointCm                 /* world position of the arena's local origin: an island-arena point p stands over the ground at anchor + p */;
  rim: ChainRef                   /* ('rim', island id): the closed structural L0 chain bounding its land (V05 §3.8) */;
  land: FaceRef                   /* its L0 land face(s) inside the rim */;
  areaHa: number                  /* the target area the rim is sized to — the supply law's A or an edited value; the land face's area within ± 1 % of it (V05 §3.6, §3.15) */;
  altitudeCm: Cm                  /* the surface datum above groundRefCm — the law's altitude floored by the rim, the root and the clearance (V05 §3.9), or an edited value */;
  groundRefCm: Cm                 /* above the ground datum: the greatest, under the projected solid, of the ground's terrain height plus the caster ceiling there — fixed at SKY, before the plots are cut (V05 §3.9 (3)); raised only by SKY-F's clearance check, `reclearIsland` (V05 §3.15 (7)) or a ground edit beneath (V05 §3.9 (5), §4.3) */;
  // elevationCm is derived at read: groundRefCm + altitudeCm — the surface datum of the island's own terrain and the `z` base of every sky mark (§8.1, §8.4)
  underside: UndersideProfile     /* the rock beneath, which shapes its shadow (V05 §3.9; J98) */;
  terrain?: Terrain               /* §2.3: its own, key = this island's; datumCm = the ground datum + elevationCm, kept in step (V05 §3.8) */;
  terrainEcho?: { river?: Id /* the ground river it echoes */; relief: 'echo'|'own'|'none';
    reliefClass?: 'plain'|'rolling'|'hilly'|'mountainous' /* §4.2 S0's relief classes: the class SKY drew for an `own` relief (V05 §3.8 (3)); absent for `echo` and `none`; read by volume 1's `terraceState` (V01 §3.17.7 (2)) and V05 §3.22 (4) */ };
  river?: Id                      /* its conjured WaterBody on its own arena (V05 §3.8) */;
  districts: Id[]; allocation: Id /* its S7b (5) sky Allocation */;
  reason: 'prosperity'|'institution'; institution?: Id /* the Institution it carries */;
  placement: { over: 'water'|'fields'|'outskirts'|'core'; byAssignment: boolean };
  occlusion?: 'opaque'|'ghost'|'offset'   /* a per-island override of the sky LayerSpec's (§8.4); absent: the layer's */;
  supply: { town: number; carried: number } /* S_town and S_carried at the last evaluation (V05 §3.3) */;
  field: { prosperity: number /* the island gradient's mean (V05 §3.11); a setAttr makes it a declared target the gradient is shifted to */; density: number; greenery: number };
  shadeBasis?: ShadeBasis         /* the island as the field's shade last read it (V05 §3.19; item 102 (e)); written only by a shade evaluation (V05 §3.19 (6)); ABSENT on an island raised or declared since the last evaluation, which casts and receives no strip until the next (J-V5.72) */;
  accesses: Id[]                  /* its SkyAccess records, in ordinal order */;
  name?: NameRef;
  state: 'floating'|'waning'|'settled'|'fallen'|'removed' /* 'removed': an author removed it (`convert removeIsland`, V05 §4.2): nothing drawn, its arena archived */; stateSince: { epoch: number; week: number }; dwellUntilWeek?: number /* waning and settled only: the week its dwell ends (V05 §3.15) */;
  removed?: { seq: number /* the removeIsland event */; generated: boolean /* its lifecycle cause was a rule (a slot draw, an epoch's raise), not a declaration — read by removedSlots(doc) to word the hold */; releasedBy?: number /* the seq of the T5 `sky` declaration that re-filled its slot when no slot was free; never an adjust('islands.count'); absent: the slot held closed (V05 §3.2 (6)) */ };
  removedAccesses: number[]       /* the ordinals of generated accesses an author deleted, held absent at every re-siting (V05 §3.10 (1)); [] by default */;
  landfall?: Id                   /* fallen only: the ground Decoration its fall laid (V05 §3.16) */;
  declared?: { outline?: true; position?: true; altitude?: true; area?: true; field?: true } /* the paths a declaring event holds (V05 §4.2; §7.2) */;
  lifecycle: Lifecycle }

interface UndersideProfile {      // the island's rocky root (J98: a shadow "related to their size, shape and the angle of the global light")
  kind: 'cone'|'bowl'|'root'|'flat' /* the radius ratio ρ(z) at depth fraction z ∈ [0, 1] below the rim's base: cone 1 − z; bowl √(1 − z²); root (1 − z)², a stalactite; flat: no root, the rim slab only */;
  rimThicknessCm: Cm             /* the cliff face at the rim: the rim's base lies this far below elevationCm */;
  depthCm: Cm                    /* the root's depth below the rim's base, to its apex; 0 for flat */;
  apexOffset: VecCm              /* local: where the apex hangs relative to the land face's centroid — a lopsided root; (0, 0) for flat */;
  tiers: number                  /* the root's slab tiers below underside tier 0 (the rim slab) (V05 §3.9); 0 for flat */;
  roughness: number              /* 0–1: the displacement share of each tier's ring (V05 §3.9) */;
  source: 'rule'|'edit' }         /* 'edit' once a setAttr set any field: then held by resizes, which scale depthCm only by the area's square-root ratio */

interface ShadeBasis {           // the one sky input a field recomputation reads (§2.9) — a copy, never a vertex (§2.2 rule 5's precedent: Works.before)
  epoch: number; by: 'generation'|'rederive'|'epoch'|'update' /* the evaluation that wrote it; 'update': Update shade now (V05 §4.2), which writes the document's current epoch */;
  anchor: PointCm; elevationCm: Cm; groundRefCm: Cm;
  surfaceTopCm: Cm               /* underside tier 0's top as that evaluation read it (V05 §3.9 (4)): the terrain's surface at generation and at a re-derivation, the full surface top at an epoch and at an update */;
  underside: UndersideProfile    /* a copy */;
  rim: PointCm[]                 /* the rim chain's lattice points in the island's local frame, in chain order from its lowest-(y, x) vertex, ≤ `shade.basisVertexCap`: a longer chain is reduced by the kernel's simplification at a 1 m tolerance (§3.4), which moves no strip bit at the 32 m cell (T-V5-20) */ }
```

**Local coordinates, one world anchor** (J-V5.1). An island's arena is laid in its own local frame centred on (0, 0)
(V05 §3.8), and the island stands over the ground plan by one integer translation, `anchor`. A move is one attribute
(V05 §4.2); nothing on the island is re-snapped, re-keyed or re-derived by it. Every reader that meets the ground
converts by that translation alone — S14 (marks and label candidates), the slab list, exports, placement and the landing
points — and every logged position on the island is local, so a later move never invalidates it. No rotation: an
integer translation keeps every lattice point a lattice point (§3.2 (7)); a turned island is a reshaped one (a `warp`
on its key).

**`removedSlots(doc)`** (`@plat/sky`, draw-free) — `{ island: Id; slot: 1|2|3; name?: NameRef; seq: number; generated:
boolean; accesses: number[] }[]`: every island record in state `removed` whose slot is still held, and every island's
`removedAccesses`, in slot order. Derived, never stored; its readers are V05 §1b's. `generated` words the hold: "the
town won't raise this island again" for a generated island, "your island stays removed" for a declared one.

**`Document.nextSkyPart: number`** (§2.9) — the part the next island takes (1 at creation), never decreasing; an event
that creates an island records the part in the island's address, so a replay reads it there. The slot (1–3) is the
count law's; the part is identity. A fallen island's part stays spent (J-V5.2).

### 2.2 The access record

```ts
interface SkyAccess {
  id: Id                          /* 'sky<part>/skyaccess:<token>' — keyed in its island's arena, where its top vertex lies */;
  island: Id; kind: 'hoist'|'ropeway'|'stair'|'lightBridge';
  top: VertexRef                  /* ('sky_access', access id): its vertex on the island's rim chain (a vertex role, §2.2 rule 7) */;
  topLanding: Id                  /* the island-side landing Reservation, kind 'landing' (V05 §3.10) */;
  ground: { at: PointCm /* world: the foot, a point attribute (§2.2 rule 5) carried with its host under a warp (§7.4) */; plot?: Id /* the ground landing plot, once placed */ };
  role: 'main'|'service'|'guarded';
  state: 'open'|'closed'          /* stored: a hand closure only; the readings `unserved` (island waning past half its dwell, or settled) and `ruined` (island fallen) are derived, never stored */;
  knownTo: 'public'|'local'|'secret'; rule: string /* the SkyAccessRow it took */; lifecycle: Lifecycle }
```

**No access is a way** (J-V5.61). A `SkyAccess` is never a way, an arena edge between arenas or a portal, and it carries
no deck plots; a raised way never reaches an island (V05 §3.22 (3)). Its foot stands on ground part-0 land only — never
on a deck face, a raised-way pier or under a raised deck (V05 §3.10 (4); J-V5.60).

Derived at read, never stored: the run (`hoist` and `stair`: the vertical drop from the rim base to the foot's ground;
`ropeway` and `lightBridge`: the 3-D length from the top to the foot), the slope, and the foot's ground height. A row's
`maxRunM` limits the **horizontal** distance from the top's world point to the foot, for both slanted kinds (V05 §2.4).
A `stair`'s path is a helix of radius `stair.radiusM` about the vertical through its foot, from the foot's ground to the
rim base, rising `stair.stepM` per step with a landing every `stair.landingM` of rise, its last turn ending at the top;
the marks and the glTF steps are laid along it (V05 §5.1, §5.5). The ground landing of a `secret` access carries the
access's `knownTo`: its `sky_landing` use is fronted by item 63's `front` mode (a warehouse or a stable, the
`sky_landing` row's front column) and withheld from every key that does not admit it (§9.2's filter), as the access
itself is.

### 2.3 The island's unit inputs (a derived view; never persisted)

```ts
// @plat/sky exports skyUnitInput(doc, island): SkyUnitInput — draw-free, assembled from committed state; its one caller is
// volume 1's unit runner (V01 §3.10.3) when the NeighbourhoodRequest it serves has layer 'sky'
interface SkyUnitInput {
  island: Id; key: PlatKey; land: FaceRef /* L0 */; rimStrip: FaceRef /* L1, never cut, never plotted */;
  claims: Id[]                    /* the institution's Reservation (an institution island) and every landing Reservation — holes the fabric cuts around */;
  landings: { reservation: Id; attach: VertexRef /* ('attach', reservation, 0): the vertex a way must end at */; access: Id; role: SkyAccess['role'] }[];
  river?: Id                      /* its crossing sites are §4.2 S1 (5)'s on the island (V05 §3.8), qualified and spanned by the unit run (V01 §3.10.3 (4)) */;
  allocation: Id                  /* the S7b (5) sky Allocation the unit runner splits over its districts (V01 §3.10.3 (4)) */;
  field: { raster: { cellCm: number /* 3 200 */; origin: PointCm /* local */; w: number; h: number; values: Float32Array /* the island's prosperity before the brush strokes, V05 §3.11 */ };
    mean: number; density: number; greenery: number } /* what the unit runner's field step reads — never recomputed from h(S_carried) */;
  context: { reason: SkyIsland['reason']; institutionKind?: string;
    districtKind: string /* 'sky-island' on a prosperity island's faces; the institution row's `districtKind` on the claim's face (V05 §2.4) */;
    districtHa: number /* IslandRule.districtHa: the land per island district volume 1's count reads (V05 §3.12) */;
    fabricHint: FabricStrategyId /* a PRIOR for S7c on every island district: the hinted template's weight × fabricPrior, never a forced strategy */;
    fabricPrior: number /* IslandRule.fabricPrior */ } }
```

SKY builds, per island, the `NeighbourhoodRequest` of V01 §2.4 — `district` the island's sky pseudo-district, `key` its
arena, `layer: 'sky'`, `boundary` the land face's runs (every rim run a hard `sky` seam, no portal), `laid` empty (so
the mode is `unit`), `strategy` absent (S7c picks it per island district, reading `fabricHint` as a prior) — and calls
`NeighbourhoodStrategy.generate`; the unit runner reads `skyUnitInput(doc, island)` for everything the request does not
carry. The view is re-assembled from the committed record, arena and allocation whenever the unit runner runs
(generation, `raiseIsland`, New random on the island; V01 §3.10.3 (6)). **The partition is volume 1's** (J-V5.28): the
island's district count and its cut are V01 §3.10.3 (2)'s, with the island's own district size — k is
`skyDistrictCount(plotLandM2, districtHa)` (V01 §3.16), its share `hood.constants.sky.plotShare` (V01 §3.14), never a
copy here (J-V5.45).

### 2.3a The shade strip (derived with the prosperity field; item 102)

```ts
// @plat/sky exports islandShadeStrip(doc, island, samples, onto): IslandShadeStrip — pure and draw-free (V05 §3.19)
interface IslandShadeStrip {
  island: Id                      /* the caster */;
  onto: 'ground' | Id             /* the receiver: the ground's field raster, or a lower island's local 32 m lattice (V05 §3.11) */;
  basis: Hash64                   /* §6.2's hash of the caster's `shadeBasis` (and, onto an island, the receiver's), the sampler's digest and the receiver heights' version under the window — the UNLEVELLED heights (§4.7; J-V5.65) — the strip reads nothing of the live island */;
  evaluated: { epoch: number; by: 'generation'|'rederive'|'epoch'|'update' } /* the evaluation that computed it; read by the clerk ("the ground last took this shade at …") and T-V5-21 */;
  window: { i0: number; j0: number; w: number; h: number } /* in the receiver's 32 m cells */;
  bits: number                    /* per cell: the sampler's sample points × its sun positions (§4.5) */;
  mask: Uint8Array                /* w × h cells, row-major, ⌈bits ÷ 8⌉ bytes each; bit (point · suns + sun) set where the ray from that point toward that sun meets this island's solid — §4.5's layout, which volume 6's building shade mask shares (V06 §3.4) */;
  cells: number                   /* cells with any bit set — the "at least one sample" area the clerk and the CSV read */ }
```

**Where it lives.** The strips of every live island onto the ground are held with the prosperity field's rasters
(§4.5), beside the daylight term's per-sample mask they are OR-ed into, and hashed exactly as those rasters are (§6.2);
the strips onto an island are held with that island's field values (V05 §3.11). Its readers are V05 §1b's; nothing edits
one (J-V5.30). **A strip is a pure function of its caster's `shadeBasis`, the receiver (the ground's heights as the
field reads them — S1's raster with the T2 terrain strokes, unlevelled, §4.7 — or the receiving island's `shadeBasis` and
terrain) and the sampler**, never of the live island, so the load path, a replay and every field recomputation rebuild
the same bits (§2.9); only the shade view's pending outline and the clerk's "has the ground caught up" read the live
island (V05 §3.19 (8)). An island without a `shadeBasis` casts no strip and receives none. When strips are computed is
V05 §3.19 (6)'s one schedule.

### 2.3b The access obstacles (for item 110's raised ways)

```ts
// @plat/sky exports skyAccessObstacles(doc): SkyAccessObstacle[] — pure and draw-free, from the committed accesses; world cm above the ground datum
type SkyAccessObstacle =
  | { kind: 'column'; access: Id; at: PointCm /* the foot (a hoist's: its landing yard's centre) */; radiusCm: Cm /* a hoist: the yard's half-diagonal; a stair: stair.radiusM + 1 m */;
      floorCm: Cm /* the foot's ground */; topCm: Cm /* the rim base, elevationCm − rimThicknessCm */ }
  | { kind: 'segment'; access: Id; a: Point3Cm /* the top's world point at the rim base */; b: Point3Cm /* the foot at its ground height */;
      clearCm: Cm /* IslandRule.accessSiting.lineClearM */ };
```

One entry per open or `unserved` access of every island that is not fallen or removed: a `hoist` or `stair` a column (its
cage or its helix rises through open air), a `ropeway` or `lightBridge` a segment. Its callers (V05 §3.22 (3); §4.3)
keep a deck, its parapet and its raised-way piers outside every column and a deck crossing under a segment `clearCm`
below it. The list is rebuilt from committed state on every call; nothing stores it. **Its size** is the document's
live access count: the generated accesses are at most `accessCount.max` per island (≤ 9 per document); hand-placed
accesses (`placeSkyAccess`) have no cap of their own, each adding one entry, their feet kept `footGapM` apart and their
tops distinct rim vertices (V05 §3.10 (4); J-V5.84). A caller tests a candidate span against the list in O(entries)
(V05 §6).

### 2.4 The rule tables (data, editable by `editTable`, §7.6; every cell `{value, unit, provenance, calibratable}`)

`IslandRule` — one row per rung that admits islands, in `@plat/tables` (`islands.json`, registry row 56):

# Host defects found by the system reads, part B: population, prosperity, plague

What this is: every defect, document-versus-code contradiction and open question in the closing sections (§9 and §10) of three host-system research notes, one row each. Rows the host would fix, decide or document carry the full detail. Rows the note marks as the map's own business are kept to one line and marked "map-side (not for the host)".

Sources read whole: `research/sf/population-system.md` §9-§10 (lines 771-954); `research/sf/prosperity-system.md` §9-§10 (lines 762-952); `research/sf/plague-system.md` §9-§10 (lines 787-962). Nothing here was executed; where a note says "inferred" or "plausible until executed", the row says so.

How to read a row: the plain statement comes first, then the pointer (file and line in the host, SettlementForge). Path short forms used in the notes are expanded: `wp/` is `src/domain/worldPulse/`, `sp/` is `src/domain/spatial/`, `map/` is `src/components/map/`, `econ/` is `src/generators/economy/`, `tm/` is `src/domain/townMap/` (the notes' own key, population-system.md line 17, prosperity-system.md line 18). The "when" column reports only what the note recommends; where the note names no remedy, it says so.

Plain glosses:
- **Preset**: one of seven shipped rule sets: QL quiet local, RR realistic regional (the default), DC dramatic campaign, SC static campaign, NC narrative campaign, LR living realm, FS full simulation.
- **Lit / dark**: a feature switched on / built but switched off.
- **Canonized**: the DM has run the premium "Map geography" action, which freezes the map's travel data (the "digest") and sets a canon marker; many movement features only run on canonized worlds.
- **Tick**: one simulated week. **Same-tick / teleport**: people or effects move instantly, with no journey.
- **M4 columns**: refugee or migrant groups that actually walk a route over weeks. **Netted transfer**: an instant move of a number of people between two places.
- **Band / rung**: prosperity is a seven-word ladder (Subsistence up to the top word); a rung is one step on it.
- **Plague front**: the system that spreads plague between mapped towns along trade and shipment links, with arrival delays.
- **Lens**: a map layer the Maps program plans that shows a host fact (territory, religion, plague) with a legend, an audience filter and a time scrub.

Counts: population 53 rows, prosperity 56 rows, plague 59 rows.

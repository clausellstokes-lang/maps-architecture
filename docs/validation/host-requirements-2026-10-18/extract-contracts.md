# Host requirements from the data contracts between the map and the host

Plain statement first in every cell, then the exact pointer (file, section, host path) for the host developer. Glossary: *host* = SettlementForge, the campaign simulation; *advance* = one turn of the simulation; *lens* = a map layer that draws one host system (plague, politics, trade, populations, faiths, prosperity, alignment); *canon* = the world as frozen into the host's record; *digest* = a fingerprint of a document's contents; *plate* = the map's own snapshot of one advance; *sway* = the map's projection of territory; *fold* = the moment the map files an incoming window.

Sources read whole: research/sf/lens-implications.md lines 382–509; docs/volumes/V13-world.md lines 1252–1346, 2690–2762, 3099–3201, 3696–3718; research/sf/fp-realm-review.md lines 620–672.

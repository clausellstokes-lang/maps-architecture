Extracted from the Maps program's research notes on the SettlementForge host (the simulator the maps sit on), at host revision `81f1cd96`. Each row is one thing the **host** would fix, decide or document. Rows marked **map-side (not for the host)** are the map module's own rules, kept to one line so the host developer can skip them.

Sources read whole: `research/sf/faith-system.md` §9 (lines 1114-1279) and §10 (1281-1377); `research/sf/alignment-system.md` §8 (801-859), §9 (862-953) and §10 (957-1080); `research/sf/trade-system.md` §9 (902-999) and §10 (1003-1151).

## How to read this

- **Plain statement first, pointer after.** Host paths are written in full (the notes abbreviate `wp/` = `src/domain/worldPulse/`, `sp/` = `src/domain/spatial/`, `map/` = `src/components/map/`, `rg/` = `src/domain/region/`, `gen/` = `src/generators/`, `econ/` = `src/generators/economy/`). A path the note does not give is marked so; the row then points at the note's own section.
- **Kinds:** *defect* = the code misbehaves; *contradiction* = a document, comment or screen says one thing and the code does another, and it is not settled which is right; *doc fix* = the code is right and the text is stale; *open question* = someone (owner or host) must decide; *map-side* = the map's own rule.
- **Words used:** *preset* = a bundle of simulation switches; RR = realistic_regional (the default), DC = dramatic_campaign, LR = living_realm, FS = full_simulation, QL/SC/NC = quiet/static/narrative. *Lit* = switched on; *dark* = present but off. *Canon / canonized* = the world's map has been frozen into a travel table (the *digest*). *Patron* = the deity a settlement seats. *Faith front* = the purple dashed line for a confirmed religious-authority channel. *Carrier* = a relationship link that faith pressure travels along. *Gate* = a settlement a caravan route passes through, where tolls, contraband and interception are decided. *M2 / M6a* = the two trade models (M2: endless supply, time buffers; M6a: finite, conserved, tolled). *Seam* = a reserved slot with nothing behind it. *Lens* = a map overlay that shows one system.

# The host-change list (H1–H30), the map milestones and the rules that bind them

Source read whole: `docs/volumes/V13-world.md` lines 3639–3753 (§8.1 where it sits, §8.2 milestones, §8.3 order, §8.4 risks, §8.5 the host's parallel track: its preamble and the table H1–H30, and the closing lines 3750–3752). Every row cites "V13 §<section> (line n)". The rows name no host file paths; the pointer is the V13 line and the host program, document or law the row names.

## Words used below (plain glosses)

- **the host** = SettlementForge, the settlement simulator the map plugs into.
- **the map module / the world** = this design's world map (`@plat/world`).
- **canon** = the frozen copy of the map's geography (routes, water, sites) that the host adopts for a campaign; **canonize** = adopt it; **re-canonize** = adopt a newer one. The **additive re-canonize** adds only newly founded settlements.
- **seat** = a settlement placed on the world map. **satellite** = a small settlement tied to a parent seat.
- **charter** = the map's facts about one spot (road, water, relief, biome) handed to the settlement generator.
- **port** = the message channel between the map and the host (not a harbour). **port verdict** (H11) *is* the harbour question.
- **advance** = one simulation time step (weeks pass). **tick** = one step inside an advance. **window** = the batch of facts the host sends after an advance.
- **the fork** = the host's own copy of the old reference map generator, which the map replaces.
- **dark / data-gated** = switched off until its data exists; absent data means the host behaves byte-for-byte as before.
- **degraded arm** = the fallback behaviour when data or hardware is missing.
- **first-paint ratchet** = the host's rule that the first screen load may never get slower; **lazy leaf** = code loaded only when first needed.
- **lens** = a themed view on the map (plague, sway, patrols, trade, populations, religion, prosperity, alignment). **sway** = political influence/territory shading.
- **M-SF** = the milestone that builds the SettlementForge connection (V13 §8.1, line 3643). **pw** = person-weeks.

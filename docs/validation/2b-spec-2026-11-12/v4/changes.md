## Instructions not folded exactly as written

- **The copy.** U-2's "a COPY of the arena taken before the first rung" is made, in A line 4 (i), by encodeArena → decodeArena with the encoded bytes asserted equal. Bit-identity before each rung is asserted on the original arena, with `bits(p)` and `state(p)`. A decoded copy may number its slots differently, so comparing bits across the two arenas would fail a correct build; the copy is compared by its encoded bytes instead.

**Vetoable deviations from the validator's wording** (each keeps the issue's substance):

1. V-MAB2-01's list of capacity-lowering changes is sharpened. It adds a rewrite of the plot's `builtBand` (the function
   reads `households.max` there) and a `setAttr` of the class (it picks the programme row the function reads). A moved
   face of a spanned passage is listed as a change of the wings' extents, not as a carry, because the span ring
   changes the capacity even when no stored composition is carried. The lifecycle kind is named: §2.8's `relocate`
   gloss now covers a Household's move.
2. V-MAB2-09's clip order adds "(two identical extents keep wing order)". Without it, two identical extents would each
   be "inside another's" and the order would be undefined. The contract also says that whatever the plan rung places
   in a contained wing at such a storey lies in the container's piece. Step 3's basement-core clause says the same for
   the core's seed piece. The pieces do not depend on where after its container a contained wing is placed (checked by
   reasoning: every face of the contained wing is already taken by its earlier container).
3. V-MAB2-10: step 3 now covers all three values of `Basement.access`. `external` is new mechanism: the core ends at
   the ground storey, and the basement's door opens in the side of `Basement.ring` whose midpoint samples lowest on
   the terrain (ties by ring index). Without this, step 3 would read a value it gives no rule for. It is recorded in
   J-A29.25 and its index row.
4. J-A28.23's and J-A28.26's index rows also gain a clause for the new rule (the validator asked only for Part A), so
   the index keeps naming each choice.
5. The first doc-check run had 10 unreviewed C3 hits, all in this lane's new text (the untouched copy has 0). The phrases

* **Locked households under re-homing (new observation, PLAUSIBLE).** §7.2 lets a household be locked. Neither §4.7's
  overflow pass nor §2.6's rule says what happens when the households past a lowered capacity include a locked one. The
  obvious rule is: pass over it, and refuse a hand edit (F-EDIT) only when the locked households alone exceed the new
  capacity. That touches §4.7, §5.2 and §7.2, which belong to other parts, so it is left for the next round.

  of the wings that reach storey s". S11 evaluates it on the base wings. The text does not say whether a stored
  composition whose composed wings have fewer storeys changes it. The reading that fits "a property of the shell alone"
  is: base wings only. A one-clause ruling in §2.6 would settle it.

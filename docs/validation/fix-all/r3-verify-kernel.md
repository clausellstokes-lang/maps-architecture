## 0. In plain words

The kernel is the part of the design that does the shape mathematics. All nine kernel items handed to round 3 are now
genuinely fixed: the parallel workers receive a copy of the town that already contains the thin strips built just
before it, a new canal or moved river may touch existing streets only at points prepared for it and the kernel refuses
any other contact, search results come back in the same order whether or not the building corners exist yet, the warp
brush keeps locked plots in place and rounds the points it moves as carefully as new ones, splitting a street keeps
every width along it, the workers' lookup tables need no rebuilding, and a reserved area's edge counts as a district
boundary. Looking for new problems found nine, one of them serious: the river-moving operator clears only the blocks
whose streets it changes, while the kernel expects it to clear every block the new water reaches, so drawing a pond
inside a block would fall back to rebuilding the whole town. The eight smaller ones: two kinds of prepared point lack
exact names, a removed street can leave a point promoted for it behind, the order of moved points in one brush stroke is
not fixed, the workers' copy check can fail after edits, the copy's size omits its search index, three wording slips,
an unassigned writer of the map border, and no kernel operation can remove just a stretch of a street. Each carries a
concrete required change; nothing is deferred.
